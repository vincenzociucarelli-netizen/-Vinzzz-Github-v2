# RegistraTEAM - Quick Start

## 🚀 Guida Rapida per il Presidente

---

## Primi 5 Minuti

### 1️⃣ Registrati come Amministratore
- Apri l'app
- Seleziona **"Crea nuova società"**
- Inserisci i tuoi dati e una password sicura
- Scegli il ruolo **"Amministratore"**

### 2️⃣ Configura la Società
Vai in **Impostazioni → Dati Società** e inserisci:
- Nome società (es. "ASD Volley Perugia")
- Sport praticato
- Logo (opzionale ma consigliato)

### 3️⃣ Ottieni il Codice Invito
- Nella dashboard, trovi il **Codice Invito**
- Questo codice serve agli atleti per iscriversi
- Condividilo via WhatsApp, email o stampalo

### 4️⃣ Crea le Squadre
Vai in **Squadre → Nuova Squadra**:
- Nome (es. "Under 14", "Serie D")
- Quota annuale
- Rate e scadenze

### 5️⃣ Attendi le Iscrizioni
Gli atleti/genitori si iscrivono con il codice.
Tu ricevi una **notifica** per ogni nuova richiesta.
Vai in **Dashboard → Richieste Pendenti → Approva**

---

## Operazioni Quotidiane

| Cosa vuoi fare? | Dove andare |
|-----------------|-------------|
| Approvare nuovi iscritti | Dashboard → Richieste |
| Registrare un pagamento | Atleti → [Nome] → Pagamenti |
| Controllare certificati | Dashboard → Certificati in scadenza |
| Vedere le presenze | Coach → Presenze |
